## Stage2: 接触感知到局部窗口精修

### 第一段：Stage2 目标与局部化建模动机

这一段先定义 Stage2 的目标：
- 输入：Stage1 输出的 initial reaction $\tilde{X}$
- 输出：refined reaction $\hat{X}$
- 作用范围：仅在 contact-relevant windows 上进行局部精修

重点写：
- Stage1 已经提供了全局合理且交互一致的 initial reaction；
- Stage2 进一步关注 hand-target contact 与局部交互几何；
- Stage2 采用局部残差修正，而不是重新生成整段序列。

可以在这一段给出最核心的残差公式：
\[
\hat{X}^{(m)} = \tilde{X}^{(m)} + \Delta X^{(m)}
\]


### 第二段：Contact-Relevant Window Selection

这一段讲 Stage2 为什么只修局部窗口，以及这些窗口如何构造。

重点写：
- 从 initial reaction 中构造 coarse contact state；
- 沿 hand-time 维度提取 contact-relevant segments；
- 为每个候选片段分配 selected hand、primary region 和 top-k target regions；
- 再将这些片段统一转化为固定长度的局部窗口。

这一段强调：
- Stage2 将问题从全序列重生成收缩为 hand-centric local refinement；
- 这是一个确定性的局部 proposal 机制，为后续 refiner 提供统一输入单元。

这里可以自然引入：
- $Y^{(m)}$
- $\tilde{X}^{(m)}$
- $s^{(m)}$
- $q^{(m)}$
- $\mathcal{Q}^{(m)}$


### 第三段：Contact-Aware Conditioning

这一段讲 Stage2 的条件输入如何构造。

重点写三类条件：
- hand-region semantic cues：selected hand、primary region、top-k target regions；
- coarse contact state：coarse contact mask 和 coarse distance map；
- local geometry cues：relative position、relative distance 和 distance velocity。

这一段要强调：
- 这些条件共同描述当前局部窗口“修哪只手、朝哪个区域修、当前 coarse contact 状态如何、局部几何关系如何变化”；
- 所有条件最终被编码为统一的 contact-aware conditioning $Z^{(m)}$。

这里可以自然引入：
- $M^{(m)}, D^{(m)}$
- $\Delta^{(m)}, d^{(m)}, v^{(m)}$
- $Z^{(m)}$


### 第四段：Contact-Aware Residual Refiner

这一段讲 refiner 主干网络如何工作。

重点写：
- Stage2 使用一个 window-level temporal residual transformer；
- $\tilde{X}^{(m)}$ 作为主输入序列；
- $Y^{(m)}$ 作为 actor-side motion context；
- $Z^{(m)}$ 通过 condition modulation 注入 refiner；
- 网络输出局部残差运动 $\Delta X^{(m)}$。

结构上可以概括为：
- self-attention：建模局部时序动态；
- cross-attention：引入 actor motion context；
- contact modulation：注入 contact-aware conditioning；
- FFN：完成特征更新。

可以在这一段给出总式：
\[
\Delta X^{(m)} = R\big(Y^{(m)}, \tilde{X}^{(m)}, Z^{(m)}\big)
\]


### 第五段：全序列重建与 Stage2 训练目标

这一段收尾说明 Stage2 如何从局部窗口恢复到整段序列，并给出训练目标。

重点写：
- 多个 refined windows 会被聚合回 full sequence；
- 采用重叠窗口的加权拼接方式，得到最终 refined reaction $\hat{X}$；
- Stage2 的训练目标以 residual reconstruction 为主，并结合 contact-aware 与 smoothness 约束。

训练目标部分建议概括为：
- residual motion reconstruction loss；
- contact-weighted loss；
- boundary / smoothness regularization；
- optional geometry-aware regularization。

这一段的作用是把 Stage2 的局部 refinement、全序列恢复和训练目标闭环起来。
