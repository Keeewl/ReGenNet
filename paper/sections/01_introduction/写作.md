## Introduction 写作框架

### 第一段：任务背景 + 高层问题 + 方法定位

这一段的目标是快速建立任务背景，并在很短的篇幅内指出现有方法的核心不足，然后自然引出我们的方法。

推荐叙事方式：

1. 先介绍 human reaction generation 的任务背景与意义，说明它是 human-human interaction generation 中的重要问题，目标是根据 actor 的动作生成合理的 reactor response。
2. 然后指出，现有方法已经能够生成整体上合理、时序上连贯的 reaction motion，但在更高要求的交互场景中，仍然难以实现 fine-grained interaction realism。
3. 这里不要一开始就展开很多细节，只需要高层指出三类核心困难：
   - reactor 的局部细粒度响应不足，尤其是手部响应容易被整体生成抹平；
   - actor 的局部交互意图没有被充分理解；
   - 即使整体动作合理，局部 contact 和 interaction geometry 仍然容易不准确。
4. 在这一段结尾引出我们的工作：
   - 我们提出 `HiReact`；
   - 它是一个 `hierarchical interaction-aware` 的两阶段框架；
   - 核心目标是在保持整体 reaction plausibility 的同时，提升 fine-grained local interaction quality，尤其是 hand-centric contact realism。

这一段要凝练，不展开方法细节，只完成“背景-问题-提出方法”的动作。

---

### 第二段：问题递进展开（问题主干段）

这一段是 Introduction 的第一个重点段，负责把问题讲透，但必须是递进式叙事，而不是平铺列点。

推荐叙事顺序：

1. 第一层问题：现有方法更多建模的是整体 motion plausibility，而不是 reactor 的细粒度局部响应。
   - 可以强调：在双人交互中，最关键、最细粒度、最容易被抹平的通常是手部及上肢相关反应。
   - 这一步自然引出为什么 hand-centric reaction 是重要难点。

2. 第二层问题：高质量 reaction 不仅取决于 actor 的整体运动模式，还取决于 actor 在不同身体部位上传递出的局部交互线索。
   - 这里强调 actor 的角色是“信息提供者”。
   - 关键不在于把 actor 本身生成得更细，而在于把 actor 拆解得更细，以提供不同层次、不同部位的 interaction cues。
   - 这一步引出为什么需要对 actor 做 structured / multi-part interaction modeling。

3. 第三层问题：即使整体 reaction 已经合理，局部 hand-target contact 和 interaction geometry 仍然容易不准确。
   - 这里要强调这类误差和“整体动作是否自然”不是一回事。
   - 也就是说，一个 motion 可以 globally plausible，但在局部交互准确性上仍然不足。

4. 最后收束一句，形成问题结论：
   - fine-grained reaction generation 需要同时解决：
     - actor-side localized interaction-intent modeling
     - reactor-side fine-grained local response preservation
     - hand-target local contact accuracy
   - 而这三者难以由单一 holistic generator 同时充分建模。

这一段写完之后，审稿人应当自然接受：

`单阶段整体生成方法不足以充分解决 fine-grained reaction generation。`

---

### 第三段：方法总述（最重点）

这一段是 Introduction 的核心方法段，要严格按照“总框架一句 + Stage1 + Stage2”的逻辑来写。

推荐叙事方式：

1. 先总括一句：
   - 为了解决上述问题，我们提出 `HiReact`，一个 hierarchical two-stage framework。
   - 它将 `globally plausible reaction generation` 与 `fine-grained contact refinement` 解耦建模。

2. 接着写 Stage1，重点说明它生成的是一个可靠的 initial reaction，而不是等待补救的粗糙结果。
   - 对 actor：
     - 构建 `Global + Multi-Part condition`
     - 从多个空间尺度提取 interaction cues
     - 使模型能够理解 actor 不同身体部位传递出的局部交互意图
   - 对 reactor：
     - 采用 `body + hand dual reaction generation`
     - 避免手部细节被整体动作生成抹平
     - 使 Stage1 能够生成 globally reasonable、interaction-consistent initial reaction motion
   - 这一部分要明确 actor / reactor 的非对称角色：
     - actor 是 fine-grained cue provider
     - reactor 是 hand-centric response target

3. 然后写 Stage2，强调它是自然延伸，而不是补锅。
   - Stage2 不重新生成整段 motion；
   - 而是在 initial reaction motion 上，针对 local contact-relevant regions/windows 做 refinement；
   - 它聚焦于 hand-centric local contact realism 和 interaction accuracy；
   - 目的是进一步提升那些难以通过 full-sequence generation 直接精确建模的局部交互细节。

4. 这一段结尾最好再用一句话总结：
   - Stage1 负责生成 interaction-consistent initial reaction；
   - Stage2 进一步提升 fine-grained local contact fidelity。

这一段要避免的写法：

- 不要把 Stage1 写成 `coarse`、`weak`、`rough` generator。
- 不要把 Stage2 写成“修正失败结果”。

这一段要强调的写法：

- `globally plausible and interaction-consistent`
- `fine-grained local refinement`
- `hand-centric interaction accuracy`

### 第四段：贡献总结

这一段简洁收束全文贡献，保持 3 点即可，不要再拆得过碎。

推荐贡献组织：

1. 我们提出了 `HiReact`，一个用于 fine-grained human reaction generation 的 hierarchical interaction-aware framework。
2. 我们提出了一个 multi-scale 的 Stage1 generator，以非对称方式分别建模 actor 的局部交互意图和 reactor 的 hand-centric response generation。
3. 我们提出了一个 hand-centric、contact-aware 的 Stage2 refinement module，用于在 initial reaction 的基础上进一步提升局部交互准确性。

这一段的作用是把全文方法压缩成审稿人可记住的 3 个点。

---

### 写作总原则

其中，第2段和第3段重点写（字数多），第三段最重点。
1. 整个 Introduction 的叙事主线必须是：
   `现有方法整体上可行，但不足以实现 fine-grained local interaction realism -> actor-side cue decomposition + reactor-side hand-centric generation 是必要的 -> local contact accuracy 仍需额外 refinement -> 因此采用 hierarchical two-stage framework`

2. Stage1 的定位必须始终保持为：
   - initial reaction generation
   - interaction-consistent generation
   - 不是“粗糙生成，等待后续修补”

3. Stage2 的定位必须始终保持为：
   - contact-aware local refinement
   - 针对最难的 fine-grained hand-target interaction details
   - 不是对整个序列重新生成

4. actor 和 reactor 的角色要明确区分：
   - actor：信息提供者，需要更细致地拆解以提供局部交互意图
   - reactor：响应生成对象，细粒度重点体现在 hand-centric local response

5. 第二段和第三段是 Introduction 的重点，其中第三段最重要。
